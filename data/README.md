# Dataset Setup

This project uses several publicly available machine-learning datasets.

Most datasets are included in their corresponding folders. The IMDB Movie
Reviews dataset is not stored directly in this repository because of its file
size.

## IMDB Movie Reviews Dataset

1. Download the IMDB Dataset of 50K Movie Reviews from Kaggle.
2. Extract the downloaded archive.
3. Rename the dataset file to:

   `IMDB Dataset.csv`

4. Place it in the following location:

   `data/imdb/IMDB Dataset.csv`

The completed directory should look like:

```text
data/
└── imdb/
    └── IMDB Dataset.csv
